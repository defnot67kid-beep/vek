# VEK Programming Language v2.5.1

VEK 2.5.1 is an interactive-installer presentation update.

## Highlights

- Full-width rotating 3D VEK scene
- Extruded 3D download/install progress bar
- Real Git percentage integration during clone and fetch operations
- No hash-character progress meter
- Cleaner installer labels without decorative double-slash separators
- New renderer-independent `ProgressBar3DModel` runtime primitive
- Existing Geometry-Dash-style runner, auto update, manual update, repair and source-only modes retained
