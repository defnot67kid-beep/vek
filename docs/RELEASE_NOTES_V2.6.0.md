# VEK Programming Language v2.6.0

VEK 2.6.0 continues the VEK 2.x line with runtime, security, installer, physics,
interaction, and developer-tooling improvements.

Highlights:
- Portable Windows installation flow
- GitHub-managed installation and updating
- Interactive installer/runtime UI systems
- Secondary-motion physics groundwork for hair and character attachments
- Door manipulation interaction examples
- Day/night cycle example flow
- Developer cheat-panel example flow
- Continued server-authoritative and deterministic security systems
- CMake integration through VEK::Runtime
