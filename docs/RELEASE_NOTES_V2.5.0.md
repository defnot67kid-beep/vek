# VEK Programming Language v2.5.0

VEK 2.5 advances the interactive UI/runtime layer and Windows GitHub installer.

## Highlights

- Rotating 3D VEK presentation scene
- Three installer download modes: latest/update, clean repair, and source-only
- 3D loading visualization
- Playable scrolling jump mini-game during installation
- Spacebar jump controls and obstacles
- Auto Update and Manual Update policies
- Always-visible, accurate installed/latest version status
- GitHub tag-based update detection
- New `VekInteractiveUiSystems` runtime module
- New deterministic runner and semantic-version tests
